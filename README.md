# web-playground

个人娱乐时写的小网站合集：纯静态 HTML，零依赖、零构建，双击就能玩。

## 站点

| 名称 | 一句话玩法 | 打开方式 |
| --- | --- | --- |
| [沙丁鱼群 2D](./sardine-boids/) | 一屏 boids 沙丁鱼群游来游去，合群、避让、绕开捕食者 | `sardine-boids/index.html` |
| [沙丁鱼群 3D](./sardine-boids-3d/) | 3D 版鱼群，带 10 条虎鲸捕食者，其中一条跟随鼠标 | `sardine-boids-3d/index.html` |

## 本地打开

两种方式，选一个就行：

1. **直接双击**仓库根目录的 `index.html`，从落地页点进各个站点。
2. **起个本地服务**（想在手机上看、或浏览器对 `file://` 有意见时）：

   ```bash
   python -m http.server 8000
   # 然后打开 http://localhost:8000
   ```

所有页面都是单文件 HTML，CSS / JS 全部内联，不联网也能跑（沙丁鱼用的是浏览器原生 Canvas，没有引入任何外部 CDN 或字体）。

## 沙丁鱼群 3D 说明

- 1000 条鱼按 boids 规则（分离 / 对齐 / 聚拢）成群，另有 10 条虎鲸捕食者，其中一条跟随鼠标游动。
- 活动范围是一个 `宽 × 高 × 400` 的浅水层，鱼和虎鲸都被硬性限制在范围内（越界会反射速度并夹回边界）。
- 虎鲸在「追捕」与「撤离」两个状态间切换：钻进鱼群核心后先散开，游远再回来，避免一直贴着鱼群。
- 鼠标只有 x/y 两轴，跟随鼠标的那条虎鲸会按鱼群中心的 z 自动下潜，能吃到深水层的鱼。

## 新增站点的约定

- 每个站点一个目录，目录名用 ASCII 短横线小写，例如 `tiny-shooter/`。
- 目录里放一个 `index.html`，样式和脚本尽量内联，保持"单文件可跑"。
- 在根 `index.html` 的卡片区加一张卡片，指向新站点的目录。
- 在上面的站点表格里补一行。

## 关于代码质量

这些都是玩票作品：想到哪写到哪，命名和结构不一定讲究，也懒得做构建和测试。看着能跑、玩着开心就够了。
